## 宏观经济学

> 宏观经济学研究一国或地区的总体经济活动，着眼于国民经济的总量分析，从国民收入核算出发，经收入-支出模型、IS-LM 模型、AD-AS 模型层层推进，再扩展到开放经济、宏观经济政策与经济增长理论

| 文章 | 内容 |
|---|---|
| [00-宏观经济学课程导论](00-intro.md) | 宏观经济学的研究对象与学科定位，从凯恩斯《通论》到现代宏观经济学的师承发展脉络 |
| [01-国民收入核算与基本指标](01-national-income-accounting.md) | GDP 的定义与三种核算方法，价格水平与失业的衡量，GDP、CPI、失业率等基本指标的局限与补充（人类发展指数、绿色 GDP） |
| [02-收入-支出模型](02-income-expenditure-model.md) | 均衡国民收入的决定，消费、储蓄与投资的决定，三部门四部门引入，净出口决定因素与乘数机制 |
| [03-IS-LM 模型](03-is-lm-model.md) | IS 曲线与 LM 曲线的含义、推导、斜率与移动，货币市场均衡，产品市场与货币市场的一般均衡及政策含义 |
| [04-AD-AS 模型](04-ad-as-model.md) | 总需求与总供给曲线的推导与移动，财政、货币、供给冲击的比较静态分析，凯恩斯陷阱、货币中性、滞胀与供给侧改革 |
| [05-失业与奥肯定律](05-unemployment-and-okun-law.md) | 失业的四派理论解释与影响，奥肯定律，经济周期的定义、阶段、类型与从早期到现代的周期理论谱系 |
| [06-通货膨胀与菲利普斯曲线](06-inflation-and-phillips-curve.md) | 通货膨胀的类型与成因、货币数量论，惯性与社会成本、收入分配与产出效应，菲利普斯曲线与预期，通货紧缩 |

| [08-宏观经济政策](08-macroeconomic-policy.md) | 政策目标体系与米德冲突，财政政策的挤出与挤进效应，货币政策三大工具与货币乘数，相机抉择与规则之争，政策局限性与协调 |
| [09-经济增长](09-economic-growth.md) | 增长的定义、度量与国别事实，哈罗德-多马模型与索洛模型，资本黄金律、内生增长理论、增长核算与增长政策 |
