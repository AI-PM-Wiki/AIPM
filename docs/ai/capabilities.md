## 模型能力与边界

做 AI 产品前，先回答两个问题：**模型能做什么？不能做什么？** 本页梳理 AI 产品经理需要掌握的模型能力地图。

## 能力强项（2025 年现状）

-   **自然语言理解与生成**：写作、翻译、总结、改写——质量接近人类
-   **代码**：编写、解释、调试、重构——强项中的强项
-   **逻辑推理**：复杂问题的多步推理（但会"聪明地犯错"）
-   **知识问答**：通用知识，训练截止日期前较可靠
-   **结构化输出**：JSON、表格、数据提取
-   **多模态**：图像/文档理解、语音对话、图像视频生成

## 常见局限

| 局限 | 产品影响 |
| --- | --- |
| 幻觉 | 事实类任务必须加检索验证 |
| 数学/精确计算 | 大数字乘除、长乘法会错——交给计算器/代码 |
| 时间敏感信息 | 新闻、股价、实时数据必须接实时源 |
| 上下文遗忘 | 超长对话丢失早期信息 |
| 逻辑陷阱 | 容易被误导性前提带偏 |
| 数据隐私 | 不要传敏感数据到公共 API |

## 模型家族速览（如何选型）

-   **旗舰闭源**（GPT、Claude、Gemini、国产旗舰）：综合最强，成本高，适合核心体验
-   **开源模型**（Llama、Qwen、DeepSeek 等）：可私有化部署，成本可控，适合数据敏感场景
-   **小模型/端侧模型**：速度快、便宜，适合简单分类、抽取等任务
-   **垂直模型**：代码、数学、多语言等专长方向

## 选型决策框架

1.  **任务难度**：简单任务用小模型，复杂推理用旗舰
2.  **数据敏感性**：敏感数据 → 开源私有化
3.  **成本预算**：按 token 用量 × 单价估算月成本
4.  **延迟要求**：实时交互场景要算推理速度
5.  **可靠性要求**：要求越高，越需要"多模型 + 兜底"架构
