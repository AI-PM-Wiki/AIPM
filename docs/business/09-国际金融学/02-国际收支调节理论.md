## 国际收支调节理论

## 自动调节机制

金本位制度下，国际收支由价格-铸币流动机制自动调节。**价格-铸币流动机制**：由大卫·休谟提出，又称物价-现金流动机制。以逆差为例，调节路径为逆差→黄金外流、国内黄金存量减少→货币供应量减少→国内物价下降→进口相对昂贵、出口相对便宜→出口增加、进口减少→贸易收支改善。货币供应量减少到物价下降的环节借助费雪方程 MV=PT 理解。

纸币本位浮动汇率制下，汇率机制自动调节：逆差→对外支付增加、对外币需求增加→本币贬值→进口相对昂贵、出口相对便宜→贸易收支改善。纸币本位固定汇率制下有三条路径：货币-价格机制（外汇储备减少→货币供应量减少→物价下降）、货币-收入机制（货币供应量减少→投资减少→国民收入下降→公众支出减少→进口减少）、货币-利率机制（货币供应量减少→利率上升→资本流入增加→国际收支改善，以资本自由流动为前提）。

自动调节存在局限。只有纯粹的自由市场经济才产生理论上所描述的作用；逆差时自动调节以紧缩国内经济为代价，造成就业与产出下降。纸币流通条件下，政府一般采取政策措施促使国际收支尽快恢复平衡。

## 政策调节机制

国际收支调节政策分四类。**融资型政策**（较短期）：动用官方储备与国际信贷便利，解决短期失衡。**道义与宣示型政策**（较短期）：靠政府谈话、约谈、官方表态引导市场，无强制约束力。**需求型政策**（较长期）：围绕社会总需求调节，分支出增减型政策（财政政策与货币政策，改变支出的量）与支出转换型政策（汇率政策、税收政策、出口补贴、直接管制，改变支出的方向）。**供给型政策**（较长期）：围绕社会总供给，包括科技政策、产业政策与制度创新政策，是根本性措施。一项政策解决一个问题可能带来副作用，需要多种政策配合使用。

## 弹性论

**弹性论**：20 世纪 30 年代提出，研究货币贬值对国际收支是否真有作用。前提为局部均衡分析、非充分就业下进出口商品供给弹性无穷大、不考虑资本流动、贸易收支最初平衡。主要观点是政府通过货币贬值改善贸易收支和贸易条件，原理是贬值通过进出口商品相对价格的变化影响进出口数量。

**马歇尔-勒纳条件**：进出口商品需求弹性之和大于 1 时，货币贬值有利于改善贸易收支；等于 1 时贬值对贸易收支不发生作用；小于 1 时贬值使贸易收支逆差扩大。**J 曲线效应**：即使马歇尔-勒纳条件成立，贬值后初期贸易收支逆差反而扩大，经过一段时间后才改善，轨迹呈 J 形。原因是贸易订单存在货币合同阶段、价格传导阶段与数量调整阶段三个时滞。**贸易条件**：$T = P_x / P_m$，即出口价格指数与进口价格指数之比。贬值对贸易条件的改善取决于进出口商品的供求弹性，本币贬值引起的多数是贸易条件的恶化，至多不变，因而贬值手段只能被短期运用。

弹性论的缺陷：建立在局部均衡分析基础上，忽略对社会总需求与总支出的影响；前提假设存在逻辑矛盾；只分析贬值对贸易收支的影响，未分析对资本流动的影响。

## 乘数论

**乘数论**：20 世纪 30、40 年代凯恩斯主义追随者运用乘数理论分析国民收入变化对国际收支的影响，又称收入论。在汇率、价格不变的情况下，国民收入的增加引起进口增加，造成国际收支状况相对恶化。一国通过需求管理政策调节国际收支失衡：逆差时用紧缩性政策减少收入、相对减少进口，顺差时用扩张性政策。

开放经济国民收入方程：$Y = C + I + G + X - M$，其中 $C = C_0 + cY$，$I = I_0 + hY$，$M = M_0 + mY$。代入得 $Y = \dfrac{1}{1 - c - h + m}(C_0 + I_0 - M_0 + G + X)$，其中 $c$、$h$、$m$ 分别为边际消费倾向、边际投资倾向、边际进口倾向。**哈伯格条件**：$E_m + E_x > 1 + m$，即进出口商品需求弹性之和大于 1 加边际进口倾向时，贬值才能改善国际收支。哈伯格条件在马歇尔-勒纳条件的基础上加入贬值的收入效应。

乘数论的缺陷：属于局部均衡分析，只分析国民收入变动对进出口的影响；前提假设存在逻辑矛盾；只分析贬值对贸易收支的影响，未分析对资本流动的影响。

## 吸收论

**吸收论**：亚历山大提出、米德发展的国际收支理论，把国际收支差额归结为一国总收入与总吸收之间的缺口，属宏观、一般均衡分析。假设不考虑资本流动、贬值为出口增加的唯一原因。核心公式为 $B = Y - A$，其中国民收入 $Y = C + I + G + X - M$，总吸收 $A = C + I + G$。逆差即 $Y < A$，支出超过收入。

改善逆差有两条路径：增加总收入（贬值、支出转向政策、贸易控制与关税补贴）或减少总吸收（紧缩性财政与货币政策）。非充分就业下增产收入有效；充分就业下产出无法扩大，只能压缩吸收。吸收论把国际收支放进宏观收支框架，缺陷在于充分就业下生产不能扩大的假设脱离现实。

## 货币论

**货币论**：约翰逊、弗兰科、蒙代尔代表的国际收支理论，从货币供求解释国际收支，属宏观、一般均衡分析。假设充分就业下实际货币需求是收入与利率的稳定函数、可贸易商品价格由世界市场决定、货币当局不对国际资本流动采取冲销政策。

货币市场均衡要求 $M_S = M_D$，货币需求 $M_D = P \cdot f(y, i)$，货币供给 $M_S = D + R$（货币乘数为 1），由此得核心公式 $R = M_D - D$。$D$ 是央行国内信贷，属主动发行；$R$ 是国际收支顺差形成的国外资金流入，以国际储备为代表，属被动发行。顺差源于国内货币供给不足，逆差源于货币供给过度。政策上只抓国内货币供给：逆差紧缩、顺差扩张。紧缩虽改善国际收支，却会伤害国内经济。

## 结构论与四理论比较

**结构论**：从供给方面解释国际收支逆差的理论，认为逆差根源在结构老化、结构单一、结构落后，政策主张改善经济结构、加速发展，通过增加投资与改善资源流动性解决问题，与供给侧结构性改革的思路契合。

四大理论从三个维度比较。分析框架：弹性论属微观、局部均衡；乘数论属宏观、局部均衡；吸收论属宏观、一般均衡；货币论属宏观、一般均衡。政策主张：弹性论主贬值但须满足马歇尔-勒纳条件 $E_m + E_x > 1$；乘数论逆差时紧缩、顺差时扩张；吸收论增收入、减吸收双管齐下；货币论只抓国内货币供给。每种理论只是提供一个看待国际收支平衡的具体视角，其本质是找到影响国际收支的因素与渠道，从而找到调节方法。
