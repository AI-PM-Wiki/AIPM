## 前沿金融实务专题课程导论

《前沿金融实务专题》是业界嘉宾讲座课。课程由财通证券、上海证券交易所、浙江证监局等机构合作支持，每讲邀请一位来自公募基金、券商、交易所、期货公司等机构的从业者主讲，把课堂金融理论连接到真实行业。

## 课程定位

课程内容沿"市场与制度—机构与业务—交易与监管—投资与人心"四条主线展开。

市场与制度层面，讲交易所沿革、发行制度从审批制到注册制的演进、多层次资本市场的板块分工。机构与业务层面，讲公募基金、券商、投行、一级市场股权投资等机构的商业模式与业务版图。交易与监管层面，讲集中撮合、集合竞价、价格笼子等交易机制，以及异常交易行为监管。投资与人心层面，讲合理收益预期、资产配置观与职业发展路径。

课程反复传达同一个判断：市场有规则、有套路、有骗局，普通人应降低预期、相信配置、用时间换空间。

## 系列主题概览

| 讲次 | 主题 | 主讲背景 |
|---|---|---|
| 基金市场的改革与发展 | 公募行业概览、规模演进、固收与货基增长逻辑、权益产品谱系与业绩 | 财通基金 |
| 券商业务全景 | 集团架构、四大主营业务、行业趋势、投行转型 | 财通证券 |
| 交易所与交易机制 | 发行制度演进、板块定位、交易机制、异常交易监管 | 上海证券交易所 |
| 一级市场股权投资 | 行业历史与数据、机构投资逻辑、项目开发与尽调 | 财通创新 |
| 投资银行业务流程 | 投行角色、板块上市标准、IPO 流程与审核 | 财通证券投行总部 |
| 北京证券交易所业务 | 新国九条、深改 19 条、板块对比、上市流程 | 财通证券保荐代表 |
| 大宗商品期货实务 | 行业生态、期货基础概念、小船理论、宏观主线 | 永安期货 |
| 公募基金投资方法 | 指数化投资、基金分类、ETF 套利、配置方法 | 财通证券资产配置中心 |
| 投资入门与职业发展 | 炒作与诈骗、收益预期、分析框架、求职建议 | 上海证券交易所 |

## 文章体系

本系列文章按"制度—机构—实务—方法—入门"的顺序组织：先看市场制度与机构全景，再进入一级市场、投行、北交所、商品期货等具体实务，最后落到公募基金投资方法与个人投资、职业发展。各篇主题相对独立，可单独阅读。
