    A --> D[播客笔记]

    B --> F[案例与实践]
    C --> F
    D --> F
    E --> F
    F --> G[复盘与沉淀]

核心关系是：信息源、书籍、播客与策略专题共同输入案例实践，再通过复盘沉淀为可复用的方法。
