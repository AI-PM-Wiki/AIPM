## F.A.Q.

**Q：这个站点是什么？**

A：AI-PM 是一个 AI 产品管理知识整合站点，详见[关于本项目](about.md)。

**Q：我是新手，应该从哪里开始？**

A：推荐按这个顺序阅读：[产品方法论](../pm/index.md) → [AI 基础](../ai/index.md) → [AI 产品实战](../practice/index.md)。时间有限的话，可以先看[学习路线](../case/roadmap.md)。

**Q：站点内容会收费吗？**

A：不会。本站免费开放，也欢迎任何形式的转载（遵循 CC BY-SA 4.0 协议，见[关于本项目](about.md)）。

**Q：如何参与贡献？**

A：参考[如何参与](htc.md)。

**Q：内容有错误怎么办？**

A：请在 [Issues](https://github.com/Hi-Yincan/AIPM/issues) 中提出，我们会尽快修正；也欢迎直接提交 Pull Request。

**Q：为什么有些页面是空的？**

A：站点正在建设中，带 TODO 标记的页面是尚未完成的骨架，欢迎参与完善。
