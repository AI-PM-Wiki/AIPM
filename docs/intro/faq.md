## F.A.Q.

**Q：我是新手，应该从哪里开始？**

A：参考[学习路线](../case/roadmap.md)，推荐按这个顺序阅读：[产品方法论](../pm/index.md) → [商业与财会](../business/index.md) → [AI 基础](../ai/index.md) → [AI 产品实战](../practice/index.md)。金融、投研或商业化方向可先读商业与财会。

**Q：站点内容会收费吗？**

A：不会。本站免费开放，也欢迎任何形式的转载（遵循 CC BY-SA 4.0 协议）。

**Q：如何参与贡献？**

A：参考[如何参与](htc.md)。

**Q：内容有错误怎么办？**

A：请在 [Issues](https://github.com/AI-PM-Wiki/aipm/issues) 中提出，我们会尽快修正；也欢迎直接提交 Pull Request。
