## 商业化与增长

商业化回答"产品如何赚钱"，增长回答"如何让更多用户用起来"。

## AI 产品的商业模式

| 模式 | 说明 | 例子 |
| --- | --- | --- |
| 订阅制 | 按月/年收费，分层（免费/Pro/企业） | ChatGPT Plus、Claude Pro |
| 用量计费 | 按 token/调用量/处理量计费 | API 服务、内容处理工具 |
| 席位制 | 按团队席位收费 | 企业协作产品 |
| 交易抽成 | 平台撮合按结果收费 | 电商/内容生成平台 |
| 增值服务 | 基础免费 + 高级能力付费 | 免费版 + 付费版模型/功能 |
| 私有化/定制 | 大客户定制部署 | 企业知识库、行业方案 |

## 定价要点

-   **成本结构要算清**：token 成本、GPU 成本、API 成本随用量线性增长——毛利是 AI 产品的生死线
-   **价值锚定**：定价对应"帮用户省下/赚到多少钱"，而不是"成本 + 加价"
-   **模型成本优化**：小模型优先、缓存命中、提示词精简，是提升毛利的核心手段

## 增长要点

-   **PLG（产品驱动增长）**：AI 产品天然适合——用户自己试用、分享、团队扩散
-   **内容营销**：AI 工具的教程、模板、Prompt 库是主要流量来源
-   **场景切入**：找到"足够痛的单点场景"切入，再扩展
-   **用户留存**：AI 工具留存难（替代品多、切换成本低），核心是持续创造"不可替代的价值"（私有数据沉淀、工作流集成）

## 关键指标

| 指标 | 含义 |
| --- | --- |
| MRR / ARR | 月/年经常性收入 |
| 毛利率 | (收入 - 直接成本)/收入，AI 产品需重点监控 token 成本 |
| 留存率 | 用户持续使用比例 |
| 单位经济 | 单个用户的生命周期价值 vs 获客成本 |
| 每次对话成本 | 支撑定价决策的核心成本指标 |
