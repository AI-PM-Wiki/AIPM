## 分析产品的通用框架

拆解任何 AI 产品，都问五个问题：

1.  **任务**：帮用户完成什么任务？任务有多痛？
2.  **能力**：底层模型/技术是什么？能力边界在哪？
3.  **交互**：用户怎么用？AI 何时介入？
4.  **信任**：如何让用户相信结果？出错怎么办？
5.  **商业**：怎么收费？成本结构如何？
