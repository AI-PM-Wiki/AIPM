## 7.3　组队：聊聊初创团队

理想的初创团队，当然是熟识多年，底层价值观相同，方法论、能力、性格互补的一群人，但这群人通常不会一开始就凑齐，往往需要经历“借事修人”到“因人成事”的转化。“借事修人”的阶段相当于练兵、演习，就算事情没成，如果锻炼了团队，也算差强人意，接下来就说说这个阶段可能出现的问题以及应对方法。
