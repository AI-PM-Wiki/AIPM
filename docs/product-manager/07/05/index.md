<a id="footnote_content_txt008_7"></a>[[7]](../04/index.md#footnote_quote_txt008_7)
冒烟测试，Smoke Test，是对新电路板基本功能检查的形象类比。任何新电路板焊好后，先要通电检查，如果板子不冒烟，则冒烟测试通过。软件研发领域借用这个词来描述新功能是否可用的初步测试。
