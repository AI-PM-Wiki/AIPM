## 8.3　 迭代：再理解敏捷

说完规划再说迭代。

提到“迭代”一定绕不开“敏捷”这个词。敏捷是一个偏技术的概念，是指以用户的需求变化为核心，采用循序渐进的方法进行软件开发。敏捷最重要的不是那些具体方法论，反而是底层的价值观、宣言和原则。对此先说说自己的理解，然后再分享一些实践。
