古希腊哲学家苏格拉底和人讨论问题时常用诘问法，又称苏格拉底法（the socratic method）或产婆法（比喻为知识接生）。这种方法首先是怀疑的：苏格拉底认为一切知识均从疑难中产生，愈求进步疑难愈多，疑难愈多进步愈大；其次是谈话方式的：采用谈话的方法，以辩论为技术来寻求真理和概念的正确定义。
