## 技术与架构简介

本专题讲产品从需求到线上运行的整条链路，分三大块：

- **开发流程**：需求 → 设计 → 开发 → 测试 → 上线 → 迭代
- **系统架构**：前端/后端、客户端/服务端、数据库、缓存、消息队列、网关、第三方服务
- **AI-Native 研发流程**：AI 深度参与后的新软件开发生命周期（SDLC）

面向 AI 产品经理：懂工程侧知识，才能和研发对齐排期、评估技术风险、判断架构取舍。不要求会写代码。

### 三大块总览

```mermaid
flowchart LR
    subgraph flow["开发流程"]
        req[需求] --> des[设计] --> dev[开发] --> tst[测试] --> rel[上线] --> iter[迭代]
        iter -->|数据反馈| req
    end
    subgraph arch["系统架构"]
        gw[网关] --> sv[服务端]
        sv --> db[(数据库)]
        sv --> ca[(缓存)]
        sv --> mq[消息队列]
        sv --> ext[第三方服务]
    end
    subgraph ai["AI-Native 研发流程"]
        art[产物提交] --> cal[评测与校准] --> nx[下一阶段]
        nx --> art
    end
    dev -.->|构建| gw
    rel -.->|上线产物| art
    nx -.->|反哺| req
```

读图方式：开发流程是主线，产出落到系统架构各组件；上线后进入 AI-Native 闭环，评测与校准把下一阶段产物反哺回主线。
