## 开源框架

开源框架帮助你快速搭建 AI 应用——从对话机器人到完整 RAG/Agent 系统。适合**验证想法**与**规模化落地**。

## 框架分类

| 类型 | 代表 | 适合 |
| --- | --- | --- |
| 应用编排 | Dify、LangFlow、Coze(国内) | 可视化搭 AI 工作流 |
| 开发库 | LangChain、LlamaIndex、Semantic Kernel | 代码开发、灵活可控 |
| RAG 专向 | LlamaIndex、向量库(如 Milvus、pgvector) | 知识库问答 |
| Agent 框架 | LangGraph、AutoGen、CrewAI | 多步骤/多 Agent 任务 |
| 本地模型运行 | Ollama、vLLM | 本地/私有化推理 |

## 选型思路

-   **产品经理视角**：优先看"多快能跑出 demo、多好维护、多活跃"——不是功能最多
-   **低代码优先**：可视化编排（Dify 类）能让产品同学自己迭代工作流
-   **上生产前评估**：框架的部署形态、性能、社区维护状态

## 注意事项

-   框架更新快，教程往往过期——以官方文档为准
-   框架 ≠ 产品：demo 跑通后，产品化还要做权限、监控、灰度
-   关注绑定：核心逻辑尽量与框架解耦，留迁移余地
