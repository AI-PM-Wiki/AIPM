## 工具与平台简介

本栏目整理 AI 产品构建过程中常用的**工具与平台**：模型服务、开源框架、评测工具、数据标注。工具变化快，本栏目保持"清单 + 选型思路"，具体版本以官方文档为准。

## 选型总原则

1.  **先明确任务**：任务决定技术，不是技术决定任务
2.  **先验证再投入**：用 Playground/试用版验证效果，再决定采购或自建
3.  **关注锁定成本**：换供应商/框架的迁移成本要在选型时评估
4.  **成本透明**：优先支持用量可视化、可预算限制的平台
