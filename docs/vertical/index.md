## 垂直领域

行业产品的对错由该行业的对象、制度和责任主体定义。核保、法条引用、诊疗建议、气象预警或安全处置，各自有监管机构和执业资格，必须按该行业的对象和制度判断。

本栏目按各行业自己的通行分类展开。金融按分业经营与央行的支付清算、征信、反洗钱职责；法律按部门法与法律职业；地球科学按学科；卫生按医疗服务、药械注册和医疗保障。

行业页写清监管机构和对象。按该行业自己的分类进入对应篇目后，交代对象、流程、数据，以及哪些动作必须由持牌或执业主体做出。

## 每篇文章写什么

每篇围绕同一组行业事实：

1.  **对象**：这个领域处理什么（账户、条文、标本、流域）
2.  **制度与流程**：谁在哪个节点做决定，依据哪类规范
3.  **数据与系统**：常用系统、字段粒度和质量陷阱
4.  **产品边界**：模型或工作流可以辅助什么；哪些输出必须由持牌机构、律师、医师或官方发布渠道做出

把边界写进 [AI 产品 PRD](../pm/prd.md) 的范围、拒答、引用和审计。评测集覆盖该行业的错误类型，方法见 [评估与评测](../ai/evaluation.md)。

???+ warning "责任主体不可替代"
    信贷审批、法律意见、诊疗结论、灾害预警和安全处置都有法定或行业责任主体。

    产品可以辅助检索、起草、分诊和质检，不能把模型输出写成最终决定。

## 阅读顺序

1.  用[能力模型](../intro/capability.md)确认工作是否依赖行业规则
2.  读对应行业页，记下监管机构和责任主体
3.  按该行业自己的分类进入对应篇目，核对工作流与系统名称
4.  用各篇中的对象和边界写方案
5.  评测与失败分析仍用站内评测方法，样本必须来自该行业
