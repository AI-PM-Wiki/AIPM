## 产品经理岗位类别

产品经理的分类没有唯一标准。同一个岗位可以同时属于多个类别：AI 应用产品可能面向 C 端用户，也可能服务企业客户；Agent 平台可能是开发者产品，也可能承担基础设施和治理职责。

判断岗位时，先看三个问题：**产品服务谁、产品解决什么问题、产品对什么结果负责**。比岗位名称更重要的是决策权、交付物和结果证据。

### 三个分类维度

```mermaid
flowchart TB
    pm[产品经理岗位]
    pm --> tech[技术对象<br/>产品的核心能力]
    pm --> users[服务对象<br/>产品为谁创造价值]
    pm --> outcome[结果责任<br/>重点优化什么结果]
    tech --> model[模型与评测]
    tech --> platform[平台与工具链]
    tech --> app[AI 应用与工作流]
    users --> c_user[C 端用户]
    users --> b_user[B 端客户]
    users --> internal[内部团队与开发者]
    outcome --> commercial[商业化与增长]
    outcome --> strategy[策略与决策]
    outcome --> data[数据与效率]
    outcome --> reliability[可靠性与治理]
```

下列页面按常见方向展开。分类用于建立认知，不代表公司的组织架构或 JD 一定采用这些名称；岗位可以跨多个维度。
