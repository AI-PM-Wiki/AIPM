## 监管科技与开放银行

RegTech 把监管义务产品化：自动取数、校验、报送和问答。开放银行把账户与支付能力以 API 提供给持牌或授权第三方。两者都把「同意」和「审计」做成系统字段。

### 核心概念

| 术语 | 含义 | 产品经理要写下的规则 |
| --- | --- | --- |
| **监管报送** | 按规定格式提交数据 | 口径变更是产品版本 |
| **开放 API** | 经同意的数据与支付能力 | 授权范围、时效、撤销 |
| **开发者治理** | 应用审核与限流 | 安全测试与事件通报 |
| **数据可携带** | 客户要求转移数据 | 格式、时限、身份核验 |
| **沙箱** | 监管试验环境 | 生产数据不得默认进入沙箱 |

### AI 产品切入点

-   报送差错解释与字段映射
-   API 文档问答
-   授权中心的风险提示
-   不自动扩大第三方授权范围

### 常见误判

-   把开放银行做成无授权数据分享
-   报送 AI「自动修正」却不留痕迹
-   忽视第三方应用的供应链安全
